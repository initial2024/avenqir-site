EXISTING AL SANDBOX · PRIVATE ONLY

Use your existing AL Sandbox, without Workstations beta

Your goal is a Chrome browser running on this very AL Sandbox and sending its screen to your phone. A private VNC and Cloudflare Access connection can do this if the Sandbox has enough RAM and browser sandbox permissions.

Read Sandbox setup and safety checks Open existing AL Console

1. Verify the real machine

Use the read-only preflight in your AL console. Check whether AVENQIR audits are installed and whether AL has at least 2 GiB assigned RAM; package installation is not automatic.

2. Install private Chrome + VNC

The opt-in installer uses an unprivileged Chrome user and VNC on 127.0.0.1 only. It does not publish a proxy, open public ports, or rotate any Orbit Android signing keys.

3. Protect and open on your phone

Create a Cloudflare Tunnel TCP route to local port 5901 and a private Access application with browser-rendered VNC and your identity as the only allowed user. Then open that protected hostname.

NOT LIVE YET: This page is an installation guide and a launcher to the official consoles. A working remote desktop requires successful tests on your AL Sandbox plus a private Cloudflare Access URL; never enter passwords here.

This is personal remote browsing, not a public proxy or VPN. Target sites may block datacenter IPs or require verification. Do not bypass site restrictions or Altare's usage rules.
