① 导出到手机

点击后生成 JSON 备份文件，保存在浏览器下载目录中。没有记录的类别会跳过。

单独管理书签

JSON 可以在另一台设备导入恢复；Markdown 仅供查看或存档，不支持反向导入。

② 从备份恢复

先选择可恢复 JSON 并预览，再选恢复模式。只修改已勾选且文件中存在的数据类别。

合并：书签按 ID / URL 去重、笔记按 ID 去重；冲突时保留本机版本；计时和小游戏等现有状态保持不变，仅填补缺失项目。达到容量限制会拒绝写入。

换设备操作：① 在旧设备导出 JSON → ② 通过你信任的离线传输方式把文件复制到新设备 → ③ 在新设备打开此页，选择 JSON → ④ 预览并选择合并或覆盖 → ⑤ 恢复后刷新书签／笔记页面。Markdown 无法作为恢复文件。

隐私提醒：导出的 JSON 未加密，拿到文件的人可以阅读其中的书签和笔记。不要在公共电脑上下载，也不要把文件发到公开仓库、聊天群或网站后台。迁移后建议及时保管或删除临时副本。

如果正在其他标签页编辑笔记，请先保存并关闭这些标签页，再执行恢复。导入后刷新相应页面才能看到新内容；当前页面不负责同步远端或保存数据库内容。
