隐私说明

个人书签、笔记、游戏记录、浏览器检查历史默认存储在当前设备的浏览器 LocalStorage 中。不同设备并不自动同步；清除网站数据或更换设备可能导致丢失，请自行导出备份。

公开网址目录由站长在受密码保护的 PHP 后台修改，数据存储于主机。所有访客可以读取已发布网址。管理员密码只用于后台，服务端保存经 PHP 密码哈希算法处理的摘要，不应重用其他账户密码。

当你主动调用 IP、DNS、GitHub 等外部接口，相关网络请求会发送给这些第三方服务，它们可能依据其隐私政策处理 IP 地址和请求数据。点击外部网站时，你将离开本站。

托管服务、网络基础设施与浏览器本身可能产生访问日志，本网站无法承诺完全匿名或不记录访问地址。本站不提供云端私人笔记同步或端到端加密保险库。

离线缓存仅用于网站静态资源，不缓存后台页面、登录信息或公开目录 API。禁止把本网站用作存放高敏感数据的地方。

留言反馈模块（启用后）：访客可自愿填写昵称、联系邮箱（选填）、主题、反馈内容和参考网页；提交的信息保存在本站 MySQL 数据库中，仅站长后台可读，不公开展示。为限制滥用，服务器会对访问 IP 做带密钥的不可直接还原摘要用于限流；托管商仍可能另行保存访问日志。留言在站长删除前可能持续保留；如不希望提供联系方式，可以留空邮箱。本站不自动发送邮件通知，也不能承诺一定回复。不要提交密码、验证码、证件号码或其他敏感信息。

本地反馈偏好：如你在留言页主动勾选“记住昵称和选填邮箱”，这两项会保存在当前浏览器本地，并在下次访问时自动填写；不存储留言正文、搜索关键词或隐私同意状态。可随时点击“清除本机记忆”。

目录显示：公开目录数量按浏览器读取并去重后的实际资源计算。搜索未命中不会自动把关键词发给第三方；只有点击相应搜索引擎或主动提交推荐表单时才会离开本站或发送信息。

可选的本地网址推荐：默认关闭。只有你在公开网址目录中主动开启后，本站才将目录分类级别的打开次数、主动收藏次数和你选择的兴趣分类保存在当前浏览器的 LocalStorage。不会保存个性化推荐所用的具体访问网址、站内搜索词、原始浏览器历史、私人笔记或私人书签，也不会把这些推荐记录发送给站长、广告方或第三方推荐服务。分类记录仅保留最多 60 天，在下次访问时清理；关闭或点击“清除记录并关闭”会删除推荐配置和记录，不影响原有书签与收藏。该数据不包含在跨设备备份中。公开目录的正常下载、访问托管商日志及你自行打开第三方网站时产生的网络请求不属于个性化推荐数据同步。

可选地区推荐：默认关闭。用户主动开启后，仅在当前浏览器获取 Intl 时区标识用于给出地区建议（浏览器时区不等于公网 IP、真实地理位置或居住地）。用户可以手动选择地区；手选优先。地区匹配和每日轮换在本机完成，未识别地区时默认隐藏推荐，不联系 IP 定位提供商、不请求浏览器 GPS 地理权限、不上传地区选择或推荐数据。只有启用状态、推荐方式及手动选择的地区代码会保存在本机 LocalStorage；关闭时删除该配置。原有站点访问与托管商日志不能因此消失。地区目录为人工精选的常见生活服务种类，不代表真实用户使用率排行，也不是安全认证。地区选项覆盖 40 个国家或地区，部分区域共享时区，因此自动建议不能证明真实所在位置；不支持的时区不展示推荐。

公开网址安全核查：目录加载时在当前浏览器检查 URL 结构、内部地址、危险协议和来源登记状态，不向第三方发送全量目录，也不自动提交任何私人书签。只有你主动点击单条“查外部风险”链接时，才会打开 Google Safe Browsing 网页，并向 Google 传送该条公开网址供查询。本站不自动调用恶意网址扫描 API；外部检测未发现危险也不能证明安全。保留的官方来源清单只表示精确地址的来源核对，不是安全证书。静态目录的构建检查由 GitHub Actions 执行，不包含访客浏览行为、IP 定位或个人浏览记录。

语言偏好：网站支持 40 个可选的界面语言，首次访问仅使用浏览器语言列表做本机匹配；浏览器语言无法识别时使用英语。主动手选的语言代码会保存在此浏览器 LocalStorage 中，优先于自动识别；恢复自动模式会删除该偏好。不会向翻译服务发送书签、笔记、使用记录或浏览器语言。界面主要导航和常用操作有本地译文，较长说明可能回退英语；公开网址原始名称、分类源字段和收录说明不会被在线机器翻译。浏览器或托管商仍可能按常规请求获知语言头信息，此功能不会上传额外语言配置。

Orbit Hub 联动：本网站只是提供 Orbit 生产入口及本机的验证码／链接文字解析辅助。不要求输入 Orbit 登录凭据，不会请求 Orbit 邮箱 API、发送或同步任何邮箱内容。用户手动粘贴的邮件片段只存活于当前网页内存；点击“本机分析”才进行解析；点击复制可能将敏感验证码或邮件链接写入系统剪贴板，剪贴板由设备或系统管理，使用后应自行清除。该功能不能验证发件人身份或链接安全。
