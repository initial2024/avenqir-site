我的项目发布版本

在手机上查 Android 项目有没有新 Release、寻找 APK/ZIP GitHub 原始下载链接。只读 GitHub 公开 API，绝不需要账号令牌。

PUBLIC REPOS

查看 Releases

默认列出你常用的公开项目；也可以增加或删除。未发布 Release 不等于没有源码或构建。

未查询

点击检查版本后，才会向 GitHub 公开 API 发请求。

版本直链有什么用？

从 GitHub Releases 返回的 browser_download_url 直接打开 APK / ZIP，不通过 SEUS 免费主机中转。历史版本和下载文件以真实 API 为准，避免虚构发布情况。

自动程度与限制

网页打开时可展示本地缓存结果，但不运行后台守护程序。GitHub 匿名 REST API 有速率限制；你可以手动刷新，页面会在短时间内复用缓存减少请求。

如果 GitHub 返回 403、404、429，会直接显示错误；不把 Draft PR 或 Actions 构建误报成已发布的 APK。
